# 📥 Inbox — capture first, sort later

This is your **capture zone**. Anything that resonates — a thought, a quote, a link, a task — lands here *without* deciding where it belongs. Lowering the friction of capture is the whole point.

## The rule
- **Capture freely.** New notes are created here by default (see vault settings).
- **Empty regularly.** Once a day (or weekly), process each item: move it to `01 Projects`, `02 Areas`, or `03 Resources` — or delete it.
- An inbox that's never emptied becomes a junk drawer. The processing habit is what makes the system trustworthy.

> [!tip] Two-minute capture
> Press `Ctrl/Cmd + N` for a new note, dump the thought, give it a rough title, move on. Decide later.
